# AI-Powered Petrochemical Trading & Enterprise Platform

> Enterprise-grade, AI-first, multi-tenant operating system for
> petrochemical trading, export, sales, finance, HR, and business
> automation.

## Vision

Build an AI-first Enterprise Operating System (AI EOS) for petrochemical
trading companies. AI is the primary operating layer while employees
supervise and approve exceptions.

## Industry Focus

Supports configurable product categories including:

-   Base Oils
-   Bitumen
-   Lubricants
-   Greases
-   Process Oils
-   Paraffin Wax
-   Solvents
-   Industrial Chemicals
-   Additives
-   Polymers
-   Future categories (no code changes)
